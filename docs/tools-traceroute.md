# Traceroute

The Tools page runs a finite traditional traceroute from the router with
[NextTrace](https://github.com/nxtrace/NTrace-core). Install the `nexttrace`
command on the router (for Debian, use the upstream nexttrace-debs repository;
other distributions can use the upstream release or build from source). OLR
does not download or install it automatically. The daemon must have permission
to send the probes; the packaged `olrd` service runs as root.

The `/api/tools/traceroute` POST endpoint accepts `{"target":"example.com"}`.
Targets must be a domain or IP literal, not a URL or command line. It runs at
most one trace at a time, with 20 hops, two samples per hop, a 75-second overall
deadline and a 64 KiB output limit. NextTrace may contact its default IP
location provider to annotate hops and create a hosted MapTrace page. When
NextTrace returns a map URL, the Tools page links to it on api.nxtrace.org.
Opening that link loads the map from NextTrace, not from OLR. Do not trace
sensitive destinations if this is unsuitable for your environment. The displayed output is generated by the
router, not the browser. Traces have no effect on router configuration.
