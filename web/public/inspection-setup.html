Inspection setup

Open Linux Router · Follow these steps on the device being inspected.

Inspection can capture credentials and private request data. Only install a certificate from a router you trust.

  1. Connect and enable inspection

    Connect this device to the router's network. The router needs mitmproxy (mitmweb) installed. Enable Inspection on this device's OLR page; it stays on until you turn it off.

  2. Download the public certificate

    Download after inspection starts and generates the router CA. This link contains only the public certificate; the private key stays on the router.

    Download certificate

  3. Install the certificate

    On iPhone or iPad, use Safari to download, then open Settings → General → VPN & Device Management, select the downloaded profile and install it. On Android, use Settings → Security → Encryption & credentials → Install a certificate → CA certificate (names vary). On a computer, import it into the system or browser certificate store.

  4. Enable trust and test

    On iPhone or iPad, open Settings → General → About → Certificate Trust Settings and enable full trust for the OLR certificate. On a computer, enable trust for websites. Browse an HTTPS website, then check Connections in OLR. Some apps reject user certificates.

  5. Stop and remove the certificate

    Turn Inspection off when finished. Normal forwarding resumes and captured data is cleared. Remove the installed CA/profile from this device's settings: stopping inspection does not remove certificate trust.

Only supported IPv4 HTTP/HTTPS traffic on TCP ports 80/443 to public destinations is inspected. IPv6, QUIC/HTTP/3, other protocols and pinned certificates are excluded. An empty capture does not mean the device made no connections.
