# Access project artwork

Bundled locally so router pages do not request third-party images at runtime.
Brand marks identify their respective projects; they do not imply endorsement.

- WireGuard, Tailscale, ZeroTier, OpenVPN, Cloudflare: Simple Icons (`https://cdn.simpleicons.org/<slug>`), in their published brand colors. Simple Icons artwork is CC0; trademarks remain with their owners.
- NetBird: `https://netbird.io/_next/static/media/netbird-icon.167cd80b.svg`
- Headscale: `https://raw.githubusercontent.com/juanfont/headscale/main/docs/assets/logo/headscale3-dots.svg` (BSD-3-Clause project).
- Nebula: `https://nebula.defined.net/img/mark.svg` (MIT project).
- IPsec uses the strongSwan implementation's logo: `https://www.strongswan.org/images/strongswan.png`.
- VLESS uses Xray's logo: `https://xtls.github.io/logo-light.svg` (MPL-2.0 project).
- VMess uses V2Ray's logo: `https://raw.githubusercontent.com/v2fly/v2fly-github-io/master/docs/.vuepress/public/readme-logo.png`.
- Hysteria: `https://raw.githubusercontent.com/apernet/hysteria/master/logo.svg` (MIT project).
- SSH uses OpenSSH's artwork: `https://www.openssh.com/images/openssh.gif`.
- Shadowsocks reuses `src/assets/way-marks/shadowsocks.svg`.

Other entries use their written names, not surrogate functional icons.
