# Service project artwork

Bundled locally so router pages do not request third-party images at runtime.
Brand marks identify their respective projects; they do not imply endorsement.

A Services tile wears a project's mark only when the tile names that project.
A service that is OLR's own feature keeps its initial on a tinted tile.

- Caddy: [`caddy/default.svg`](https://github.com/GLINCKER/thesvg/blob/main/public/icons/caddy/default.svg)
  from [theSVG](https://thesvg.org/icon/caddy) (MIT), in the library's own
  colour (`#1F88C0`). The file is unmodified. It is a plain glyph rather than a
  self-contained app icon, so the launcher draws it on its white tile with
  padding — the same backing Access gives its project marks — instead of edge to
  edge.

Trademarks remain with their owners. No launcher artwork is generated or drawn
locally.
